EvacuAI SVG import guide
============================================================

Tinkercad extrudes an entire SVG file into ONE shape.
So import ONE ROOM FILE AT A TIME from svg/rooms/ to keep
each room a separate, renameable object.

For each imported room:
  1. Import the .svg (units: Millimeters)
  2. Set Height = 20 mm (rooms/stairs/corridor)
  3. Rename the shape to EXACTLY the filename (no .svg)
  4. Set Z position per floor:
       Ground   Z = 0
       Second   Z = 30
       Third    Z = 60

Do NOT group different rooms together.
